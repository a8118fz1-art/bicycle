# 功率機設定頁「組」對照表（Mega FW 0.21M 串接計畫）

> 由 `dyno_f1timer/gen_plans.py` 解析 `ems_head_unit_mega.ino` 自動產生，**不要手改**；改 .ino 後重跑 `python gen_plans.py`。

## 功率機設定
- 功率機**只認 F1**：每按一下 = 下一組；設定 N 組，按滿 N 下自己停。組長不影響換組。
- **N = F1 的下數，F2 不算**（60A1 N=6、60A2 N=6、60B N=10、CMP1 N=6、CMP2 N=6、C90A N=4、C90B N=4、C120 N=4）。**第一次正式跑時確認功率機在最後一下 F1 後真的自己停。**
- **每一組（含第 1 組穩定組）組長都設 600 s**，只要求不會在 F1 之前自己結束。
  - Mega 每組內容最長 440 s（CMP2 G1）、整組（含 HOLD）最長 475 s（CMP2 G1），都 < 600 s（gen_plans.py 與測試檢查）。
  - 穩定組：F2 開始，**必須在 600 s 內按第一下 F1**（否則穩定組自己結束）。
- 組數：功率機 N = 穩定組 + Mega 組數，**功率機最多只能設 10 組**（2026-10-19 確認），所以一個計畫最多 5 段。

## F1 怎麼按（共 N 下）
- F2 → 第 1 組（穩定組）。轉速穩定後**操作員按第 1 下 F1**（→ 功率機第 2 組），3 s 內 Mega 按 \* → Mega G1。
- 之後 dyno_f1timer 只跟著 Mega：在 **Mega 每一組結束前 3 s** 送 1 下 F1（休息組也一樣）→ 功率機和 Mega 一起換組。
  - 「組結束」= 下一組開始（韌體 `planNextAt`，從 \* 起的絕對排程）= 內容 + HOLD（內容跑完後阻力 0 等）。內容結束和組結束不同；以組結束為準，所以 F1 落在 HOLD 期間、不會切掉內容。
  - 剩餘時間 = 這組長度 − 已過時間；已過時間 = 現在 − 狀態檔的 `grp_since_pc_ms`（記錄頁收到 Mega 換組的時刻，誤差 ≤ 0.5 s）。每組重新對齊，沒有獨立 PC 倒數表。
- **最後一組沒有下一組**：Mega 內容跑完就 `PLAN DONE`（不 HOLD），程式看到 PLAN DONE 時送**最後 1 下（第 N 下）**，功率機按滿 N 下自己停。
- 按鍵數：60A1 = 操作員 1 + 程式 5 = 6；60A2 = 操作員 1 + 程式 5 = 6；60B = 操作員 1 + 程式 9 = 10；CMP1 = 操作員 1 + 程式 5 = 6；CMP2 = 操作員 1 + 程式 5 = 6；C90A = 操作員 1 + 程式 3 = 4；C90B = 操作員 1 + 程式 3 = 4；C120 = 操作員 1 + 程式 3 = 4。

## 狀態檔停更（> 3 s 沒更新）：不停止
- 停更期間不送、不停止，終端一行顯示；恢復後看 Mega 目前組號，缺幾下就補幾下，每下間隔 1.5 s，每下送前重讀狀態檔＋確認前景，已送數不會超過 Mega 實際走到的地方。

## 韌體的 30 s 餘裕 / HOLD / LATE（PM 待決）
- 0.11M 每組 = 內容 + 30 s 進位到 10 s + 5 s，多出的時間 HOLD（阻力 0），LATE 門檻 6 s。這是當初假設「功率機組長固定、F1 照 PC 時刻送」留的餘裕。
- 現在功率機只認 F1、F1 跟著 Mega 組結束送，**這段餘裕對功率機已不需要**，只讓每組多 30～40 s 阻力 0 的空錄。建議之後韌體版本拿掉（組 = 內容；或只留幾秒 HOLD），LATE 檢查也可一併簡化。本次不改韌體。
