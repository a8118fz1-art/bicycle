EMS Bike 手把測試單元

取代上控 HMI 的獨立測試裝置。不需要電腦或瀏覽器，直接對下控跑完整的 SET_CONTROL → START 序列，並顯示 ACK 結果、錯誤旗標與鏈路狀態。

UART 19200 8-N-1

接線與供電

接線前務必確認兩件事

一、不要接下控的 HMI 電源腳。本機由 Type-C 供電，兩組電源並聯會互相灌電。 只接 TX / RX / GND 三條線。

二、量下控 TX 閒置電壓。若為 3.3V，D9 這條線需分壓後再接下控 RX （串 1kΩ、對地 2kΩ），直接接 5V 可能損壞下控輸入。下控 TX 為 3.3V 進本機 D8 則安全，不需處理。

本機腳位方向接到下控備註
D8←TX接收 STATUS_REPORT 等封包
D9→RX送出指令與心跳，準位需先確認
GND↔GND必接。接之前先量兩端 GND 電位差應接近 0V
Type-C—（不接下控）本機電源，接充電器或電腦皆可

接上後沒有反應？若畫面一直是 NOLINK，先把 D8 和 D9 對調再試 —— 兩條線是交叉接的，接反最常見。

最小／最大值有個盲點：它分不出「大部分正常、偶爾尖峰」和「從頭到尾都是垃圾」。 這兩種的成因與修法完全不同，所以故障時畫面會直接把波形畫出來 —— 現場不需要接電腦。

最快的鑑別方式仍然是拔掉感測器。拔掉後波形若還在跳動，代表下控的輸入端本身就在抓雜訊， 與感測器無關；若變成一條平線，問題就在感測器或它的線路上。

畫面上的星號記號

好記的巧合：按 * 鍵之後，畫面上的 * 記號就會消失。 兩者本來是不同的東西 —— 畫面的 * 是狀態顯示，按鍵 * 是開始 —— 但按下開始就會把設定送進下控，記號自然跟著消失。

畫面上的 * 代表你設的值與下控回報的 TGT 不一致，也就是設定還沒生效。 它不是通訊錯誤。按下開始鍵之後 * 應該消失、TGT 應該變成你設的數字 —— 這是判斷指令有沒有真的送進去最快的方法。

送出指令後的四種結果

按下開始鍵 * 之後，看第五行的訊息落在哪一類 —— 四種結果指向完全不同的原因。

看到通訊結論與下一步
RESISTANCE ON 正常 完全成功。* 消失、TGT 對上設定值、徽章變 RUN。
NG … 正常 下控收到了、聽懂了，但拒絕。雙向通訊沒問題，問題在下控的狀態機或參數。原因碼就是答案。
ACK TIMEOUT … 可疑 下控沒有回應。若隨後出現 LATE ACK，表示只是慢，不是沒回； 若始終沒有，代表它收得到卻不回應 —— 依協定即使拒絕也應回覆結果碼。
NOLINK 中斷 連封包都收不到。先查接線、準位與共地，此時按任何鍵都沒有意義。

標準測試流程

基本啟動測試

  1. 確認徽章不是 NOLINK。真機需要先踩踏喚醒才會開始通訊。
  2. 用 ↑ ↓ 調整目標值。從低值開始，例如 KP 1.0。此時只改本機設定，阻力不會動，* 會亮起。
  3. 按開始鍵 *。送出完整的 SET_CONTROL → START 序列。
  4. 檢查三件事。訊息是否為 RESISTANCE ON、* 是否消失、TGT 是否等於你設的值。
  5. 運轉中再調整 ↑ ↓。此時會即時送出 SET_CONTROL，TGT 應跟著變動。這一步驗證的是「已啟動狀態下改值」。
  6. 按停止鍵 #。訊息 STOPPED，徽章回到 READY。心跳會繼續送出，這是正常的。

故障狀態下的測試

  1. 記下 ERR 欄位的值。對照第 3 節的旗標表，可能是多個錯誤疊加。
  2. 按一次開始鍵 * 清除錯誤。此時送出的是 RESET_ERROR。
  3. 觀察錯誤是否立刻復發。馬上又回到 FAULT，表示故障是現行的、不是殘留狀態。
  4. 再按一次開始鍵 *，強制送出啟動序列。用來確認下控在故障狀態下是接受、拒絕、還是不回應控制指令。三種結果都是有效資訊。

使用注意事項

本機會持續送出心跳。開機後以每秒一次的頻率送出 HEARTBEAT， 按下停止鍵也不會停。這是刻意的 —— 心跳一旦中斷，下控會在 3 秒後關閉阻力、30 秒後斷電。

因此本機插著的時候，下控的 30 秒自動斷電不會發生。 若需要讓下控斷電，請拔除本機電源或拔掉 D9 這條線，再等 30 秒。

本機不會主動開啟阻力。開機後停在待機狀態，只送心跳，必須按下開始鍵 * 才會送出控制指令。

隨時可以長按停止鍵 # 安全歸零。目標值歸 0 之後再送 STOP，是最保險的中止方式。
