# 功率機 F1 自動定時器 操作說明（Mega FW 0.12M 計畫 60A1 / 60A2 / 60B / CMP1 / CMP2）

程式**只會送 F1**，不讀畫面、不攔截鍵盤、不開 Mega 的 COM 埠（COM 埠由記錄頁獨佔）。它從記錄頁每秒寫的 `mega_status.json` 看 Mega 在第幾組、這組還剩幾秒：**在 Mega 每一組結束前 3 s 送 1 下 F1**，功率機和 Mega 一起換組。F2、第一下 F1、F4 存檔、歸零都由人操作。

**功率機只認 F1**：每按一下 = 下一組；設定 N 組，按滿 N 下自己停（N = F1 的下數，F2 不算；60B N=10，其他 N=6）。**第一次正式跑時確認功率機在最後一下 F1 後真的自己停**。組長不影響換組。

## 第一次使用（每台電腦一次）
1. 安裝：執行 `pywinauto_offline\install.bat`（在 dyno_f1timer 資料夾裡；**wheel 檔不在 repo**，從 `Downloads\dyno_f1timer_v2.zip` 的同名資料夾複製過來）（離線、`py -3.13`，最後印出 OK）。不需要其他套件。
2. **權限一致**：功率機軟體、命令列、瀏覽器用同一種權限開（都一般使用者）。不一致時程式開始前就拒絕。
3. **關掉螢幕保護、自動鎖定、睡眠，暫停 Windows Update**（計畫最長約 44 分鐘不碰鍵鼠）。程式執行中會要求系統不睡眠，但**鎖定必須在設定裡關**。
4. 記錄頁用 repo 根目錄的 `head_unit_logger.html`（0.12M 計畫名稱版）（Chrome 或 Edge），**和 dyno_f1timer、功率機軟體在同一台電腦**（狀態檔新鮮度用這台電腦的時鐘判斷；不要放網路磁碟、不要由別台寫）。
5. **視窗擺法：記錄頁和功率機視窗左右並排，記錄頁不要最小化、不要被完全遮住**（Chrome 會節流被遮住的分頁；記錄頁已改成收到 Mega 資料就寫狀態檔，並排是雙重保險）。
6. **Chrome 記憶體節省**：到 `chrome://settings/performance` →「一律保持啟用這些網站」加入記錄頁（本機檔案就加 `file:///` 路徑），或直接關閉「記憶體節省」，免得記錄頁被捨棄。Edge 在 `edge://settings/system` 的「睡眠索引標籤」做同樣設定。
7. Mega 燒 **FW 0.12M**（待機畫面顯示 `FW 0.12M`）。開機會自動保證歸零（`BOOT ZERO`）。

## 上機前必做（每次換版本、換電腦）
1. 記錄頁連線 → 按「選擇狀態檔 mega_status.json」，存到 `config.toml` 的 `status_file`（預設 `D:/EMS_LOG/mega_status.json`）；畫面要顯示「寫入中 第 N 次」，沒有紅字。
2. Mega 用 ↑↓ 選到 `PLAN 60B` → 雙擊 `檢查.bat`（= `py -3.13 dyno_f1timer.py --check`）：視窗 1 個、權限一致、切前景成功、狀態檔新鮮、sel 正確。不送任何鍵。
3. `py -3.13 dyno_f1timer.py --plan 60B --dry-run`（沒有 .bat，命令列執行）：按 Enter 當第一下 F1，照 .ino 時程模擬每一下 F1 時刻，不送鍵（只驗按鍵數與不鎖定，**不會**讀狀態檔）。
4. **影子演練** 雙擊 `試跑60B_shadow.bat`（= `py -3.13 dyno_f1timer.py --plan 60B --shadow`）：開始前檢查與正式相同；讀真的狀態檔、跟著 Mega 跑完整邏輯，只在 log 寫「SHADOW 此時會送 F1」，**不送鍵、不切視窗**。log 也記下操作員每一下實際按的 F1（「SHADOW 操作員 F1 比程式會送的功率機第 k 組 早／晚 x s」）。程式「會送」的時刻只看 Mega，跟你實際按的時刻無關。操作員照常手動：F2 穩定後在功率機視窗按第一下 F1、3 秒內按 \*，之後每組自己看 Mega 按 F1（按鍵只記錄、不會停止）。跑完全程 60B，核對 log 每一下「Mega Gk 剩 x s」應約 3 s、最後一下在 PLAN DONE。
5. 第一次正式前先試跑 60B 前 3 組，對照功率機檔案各組起訖和 `f1timer.log`（量 F1 延遲與組長誤差）。

## 功率機設定頁（每個計畫一次）
- **組數**：60B **10 組**，60A1／60A2／CMP1／CMP2 各 **6 組**（= 第 1 組穩定組 + Mega 組數）。**功率機最多只能設 10 組**（2026-10-19 確認），所以 0.12M 把原本 12 組的 60A、COMP 各拆成兩個計畫，兩個之間照樣先跑 REST5 休息 5 分鐘。
- **組長：每一組都設 600 s**（含第 1 組穩定組）。組長只要求不會在 F1 前自己結束：Mega 每組內容最長 440 s、整組（含 HOLD）最長 475 s，全部 < 600 s。**穩定組要在 F2 後 600 s 內按第一下 F1。**
- 完整表與來源：`arduino/docs/DYNO_GROUP_TABLE.md`。

F1 共幾下（= 功率機組數）與每下時機（`功率機組:內容(這個 Mega 組開始後幾秒送 F1 結束它)`，DONE = Mega PLAN DONE 時送最後一下）：

| 計畫 | 功率機組數 | F1 下數（操作員 + 程式） | 各組 |
|---|---|---|---|
| 60A1 | 6 | 1 + 5 = 6 | 1:穩定(F2)、2:S18(+422)、3:休(+332)、4:S7(+382)、5:休(+332)、6:S8(DONE) |
| 60A2 | 6 | 1 + 5 = 6 | 1:穩定(F2)、2:S9(+472)、3:休(+332)、4:S10(+412)、5:休(+332)、6:S11(DONE) |
| 60B | 10 | 1 + 9 = 10 | 1:穩定(F2)、2:S12(+262)、3:休(+332)、4:S13(+252)、5:休(+332)、6:S14(+252)、7:休(+332)、8:S15(+252)、9:休(+332)、10:S16(DONE) |
| CMP1 | 6 | 1 + 5 = 6 | 1:穩定(F2)、2:S7(+382)、3:休(+332)、4:S8(+192)、5:休(+332)、6:S11(DONE) |
| CMP2 | 6 | 1 + 5 = 6 | 1:穩定(F2)、2:S9(+472)、3:休(+332)、4:S10(+412)、5:休(+332)、6:S12(DONE) |

## 正式流程
1. 記錄頁連線、選好狀態檔（**計畫中不要動記錄頁的串口和 USB**：重新連線會讓 Mega 重開，計畫中斷）。記錄頁和功率機並排，不要最小化或遮住記錄頁。
2. Mega 選到 `PLAN 60A1`。雙擊 `跑60A1.bat`（其他計畫用同名的 `跑60A2.bat`／`跑60B.bat`／`跑CMP1.bat`／`跑CMP2.bat`）。程式先檢查視窗、權限、狀態檔、Mega 選的計畫；任何一項不對就不開始並說明原因。
3. 顯示 `ARMED`／「尚未偵測到 t0」。**歸零 → 功率機按 F2（= 第 1 組穩定組）→ 等轉速穩定**。這段時間按的鍵都忽略。
4. **穩定後點一下功率機視窗，按第一下 F1（→ 功率機第 2 組）；3 秒內在 Mega 按 \*（→ Mega G1）**。F1 必須按在功率機視窗上，按在別處程式不認（會嗶並提示）。終端出現大字 `T0` 才算數。程式會確認 Mega 在 F1 後 −1～+6 s 內進 G1（F1 後 8 s 還沒進就停止）。
5. 之後**完全不要碰鍵盤**（滑鼠也不要動）。程式在 Mega 每一組（含休息組）結束前 3 s 把功率機切到前景（滑鼠會被移到螢幕左側外，屬正常）、確認後送 F1；Mega 最後一組 `PLAN DONE` 時送最後一下（第 N 下），功率機按滿 N 下自己停（N = F1 下數，F2 不算；第一次正式跑時確認最後一下後功率機真的停了）。**不要自己按 F1**。
6. 終端顯示 `DONE 程式 … 下 F1 全部送完`，**手動按 F4 存檔**、記錄頁下載 CSV。

## 會自動停止的情況（嗶聲＋大警告）
- t0 之後按了**任何鍵**：包括記錄頁打 **M 標記**、在其他程式打字、Fn／音量／媒體鍵、再按 F1。整個計畫期間不要用鍵盤。
- Mega 事件 `ABORT` / `LATE` / `NOT RUN`、重開（`BOOT` 或 millis 倒退）、計畫沒 PLAN DONE 就結束。
- 送 F1 前會再讀一次狀態檔，算出「不該送」就不送並停止（不會多送）。
- \* 不在第一下 F1 後 −1～+6 s 內（F1 後 8 s 還沒進 G1）、Mega 組號倒退、狀態檔沒停更卻跳組。
- 功率機視窗不是剛好 1 個、切不到前景、送前確認前景不是功率機。

**狀態檔停更不會停止**（2026-10-16 60B 實跑：HDD 寫慢，舊版因此停止、功率機卡在第 4 組）：終端顯示一行「⚠ 狀態檔 N s 沒更新：暫停送 F1，等待恢復」，不嗶、不送。恢復後看 Mega 目前在第幾組、剩幾秒，算出應該已送幾下，**缺幾下補幾下**，每下間隔 **1.5 s**，每下送前都重讀狀態檔＋確認前景，不會多送。停更期間功率機換組會晚，那幾組的起訖和 Mega 對不齊；log 會寫「補送」。**停更超過約 2 分鐘時，補送完請看功率機畫面的組號是否 = Mega 組號 + 1；不符就關掉程式（Ctrl+C 或關視窗），其餘手動按 F1 完成。**若記錄頁真的當掉、狀態檔一直不恢復，程式會一直等 → 自己看 Mega 手動按 F1，或按 Esc 停程式。

停止後程式**不再送任何鍵**，並印出剩下每一下 F1 的推算**本機時刻（HH:MM:SS）**與倒數（以 Mega 畫面為準：每組結束前約 3 s、最後一下在 PLAN DONE）。Mega 若已中止或重開，它會自己保證歸零；不要再補按 F1，直接停功率機、F4 存檔。

## 怎麼中止
- **按任何一個鍵**（例如 Esc），不用先點終端視窗，自動送 F1 立刻停止。或點終端後按 Ctrl+C。
- Mega 計畫：長按或短按 \#，Mega 保證歸零；程式會從狀態檔看到並停止。

## 記錄
`f1timer.log`：t0、每次 F1（第幾下、Mega 第幾組剩幾秒）、停止原因、狀態檔停更開始／恢復、補送，毫秒。
